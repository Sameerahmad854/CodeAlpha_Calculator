# CodeAlpha Calculator

A responsive and interactive calculator built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

## Features

* Addition, subtraction, multiplication, and division
* Decimal calculations
* Clear (`AC`) button
* Delete (`DEL`) button
* Divide-by-zero error handling
* Keyboard support
* Responsive design for different screen sizes
* Smooth button hover and click effects
* Floating-point precision handling
* Accessibility support with `aria-live`

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* CSS Grid

##  Keyboard Controls

| Key           | Action            |
| ------------- | ----------------- |
| `0 - 9`       | Enter numbers     |
| `.`           | Decimal point     |
| `+`           | Addition          |
| `-`           | Subtraction       |
| `*`           | Multiplication    |
| `/`           | Division          |
| `Enter` / `=` | Calculate result  |
| `Backspace`   | Delete last digit |
| `Escape`      | Clear calculator  |

##  How to Run

1. Clone the repository:

```bash
git clone https://github.com/Sameerahmad854/CodeAlpha_Calculator.git
```

2. Open the project folder:

```bash
cd CodeAlpha_Calculator
```

3. Open `index.html` in your browser.

You can also use **VS Code Live Server** to run the project.
